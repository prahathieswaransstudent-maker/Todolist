# Ex03 To-Do List using JavaScript
## Date: 30 October 2026

## AIM
To create a responsive To-do application using HTML, CSS, and JavaScript. The
application allows users to add, edit, complete, delete, filter, and clear
tasks, while saving task data in the browser.

## ALGORITHM
### STEP 1
Build the HTML structure (index.html).

### STEP 2
Style the App (style.css).

### STEP 3
Add task creation, editing, completion, deletion, filtering, task counts, and
clear-completed functionality.

### STEP 4
Create a To-do application using Javascript.

### STEP 5
Save and restore tasks with browser local storage.

### STEP 6
Test task operations, filters, persistence, keyboard controls, and responsive
layout.

### STEP 7
Open `index.html` in a modern browser. No package installation or server is
required.

### STEP 8
Check the layout at desktop and mobile widths and refine the styling.

### STEP 9
Optionally deploy the static files to a web host.

### STEP 10
Optionally upload the files to GitHub Pages for free hosting.

## PROGRAM

The complete program is provided in these files:

- `index.html` — accessible page structure and controls.
- `style.css` — responsive application styling.
- `script.js` — task behavior and local storage.

### How to use

1. Open `index.html` in a browser.
2. Enter a task and select **Add task** or press Enter.
3. Use the checkbox to mark a task complete. Select **Edit** to change an
   active task, or **Delete** to remove a task.
4. Choose **All**, **Active**, or **Completed** to filter the list.
5. Select **Clear completed** to remove all completed tasks.

Tasks remain saved in the current browser using local storage.


## OUTPUT

The browser displays a responsive to-do list. Users can manage tasks and see
the updated task count and filtered list. Tasks persist after reloading the
page in the same browser.


## RESULT
The To-do list application was created and is ready to run in a modern browser.
